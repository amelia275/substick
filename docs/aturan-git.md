# Aturan Git sederhana

- `main`: versi stabil untuk demo.
- `develop`: integrasi fitur.
- Gunakan branch seperti `feature/home-feed`, `feature/podcast-player`, `feature/api-posts`.
- Gunakan pesan commit jelas, misalnya `feat: add notes feed`.
- Jangan commit `.env`, kredensial, cache, atau file build.
